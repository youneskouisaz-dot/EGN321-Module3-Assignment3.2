# EGN321 Module 3 - Assignment 3.2

## Capstone Candidate Workbook

This repository contains the materials for Assignment 3.2, Capstone Candidate Workbook: Source, Audit, and Suitability Review.

## Selected Workbook

The selected capstone candidate is a public sample inventory workbook used to track inventory quantities, unit prices, inventory value, reorder levels, reorder timing, reorder quantities, and discontinued items.

The workbook supports a real inventory-management process and includes formula-based calculations and reorder logic that can be audited and improved later in the course.

## Purpose of the Workbook

The workbook helps a user:

- Track inventory items
- Monitor quantity in stock
- Calculate inventory value
- Define reorder levels
- Track reorder timing
- Record quantity currently being reordered
- Identify discontinued products
- Highlight items that may need to be reordered

## Main Inputs

The main manual inputs include:

- Inventory ID
- Item name
- Description
- Unit price
- Quantity in stock
- Reorder level
- Reorder time in days
- Quantity in reorder
- Discontinued status

## Main Outputs

The workbook calculates and displays:

- Inventory value
- Reorder-related highlighting or indicators

## Initial Concerns

Several areas deserve further investigation:

- Reorder levels are entered manually and may be inconsistent
- Reorder logic may be difficult for a new user to understand
- The workbook does not clearly explain how reorder levels or reorder quantities should be determined
- Input validation may be limited
- Important business rules may depend on hidden or undocumented assumptions

These concerns are treated as suspected risks and not confirmed defects.

## Why This Is a Good Capstone Candidate

The workbook has a clear operational purpose, contains formulas and decision logic, supports a real inventory workflow, and has enough complexity to demonstrate engineering analysis and improvement.

It is also small enough to understand, test, document, and improve during the remainder of the course.
